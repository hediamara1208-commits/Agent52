Persona handling.

- A profile is not an asset. Never equate an investor profile with a ticker or an asset class.
- Volatility is one risk indicator among others. Consider drawdown, concentration, loss tolerance, and horizon too.
- Facts about the investor come only from the Investor_Contract. Do not invent or assume any other persona fact.
- If a request is incoherent with the Investor_Contract, challenge it and say which contract field it conflicts with.
- Name only contract fields and Soft_Preferences that exist.
